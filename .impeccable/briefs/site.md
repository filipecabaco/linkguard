# Surface brief: LinkGuard GitHub Pages site (docs/index.html)

Mode: Persuade

Audience: people the author sends the link to, non-technical. Job: understand what LinkGuard is in seconds, trust it, install it. A short developer line at the bottom points to GitHub. No live link checker on the page (declined).

## Direction contract

THESIS: The page answers what a nervous person actually asks; installing is one of the answers, and it's open by default. Refuses the category template (headline + subcopy + button over a row of feature cards).

OWN-WORLD: Return to Sender (DESIGN.md). Kraft band, thermal-white label, iron ink, franking-red double-ruled stamp, yellow sticker for "look twice". Archivo condensed headlines; mono addresses.

STORY: "Is this link safe?" → a stamped example shows the answer → the visitor's own questions are listed in a ruled slip → the install answer is already open with their browser picked and a working Download button.

FIRST VIEWPORT: kraft band (mark, LinkGuard, Install/Privacy/GitHub). Two columns: left has the headline at display scale, lede, and the example address label with a tilted NOT SAFE stamp (labelled as an example); right is a ground-tinted aside headed "You might be wondering", a ruled list of questions with "How do I install it?" open showing detected-browser steps and the Download button. Stacks on phones with the install answer first after the hero.

FORM: Questions first (seed:0f6e50c0ca199999, dealt lead). Sketch: .impeccable/mocks/decision/site-questions.html.

SIGNATURE: the question slip, where every answer is a ruled entry and the open one is the action. Motion: the stamp lands once.
